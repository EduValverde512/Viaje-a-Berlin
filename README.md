# Rave de ánimo

Archivos listos para subir a GitHub y publicar después con GitHub Pages.

## Contenido

- `encuesta-berlin-grupo.html` — encuesta para compartir con el grupo.
- `presentacion-rave-de-animo.html` — presentación visual final.

## Subida rápida

1. Crea un repositorio nuevo en GitHub.
2. Sube estos archivos a la raíz del repo.
3. Si quieres publicarlo, activa GitHub Pages desde Settings > Pages.
4. Selecciona la rama principal y la carpeta `/root`.
5. GitHub te dará una URL pública para compartir por WhatsApp.

## Recomendación

- Usa la encuesta como primer enlace.
- Usa la presentación como segundo enlace para que voten con contexto.
